# 5.6 Eksperimen Gabungan 204 Fitur — Apa Isinya

Tugas PSD bagian ini: **gabungkan 3 polutan = 204 kolom** (68 NO₂ + 68 SO₂ + 68 CO) →
**reduksi dimensi 204 → 74 → 37** → **cluster tiap dimensi** → **eksperimen cluster terbaik
via silhouette** → hasilnya dipetakan di 5.7. Karena ada **dua versi interpolasi**,
eksperimennya ganda:

| Aspek | 5.6a Linear | 5.6b Polynomial |
| :--- | :--- | :--- |
| **Sumber** | `data/ekstraksi_fitur_linear.csv` | `data/ekstraksi_fitur_polynomial.csv` |
| **Matriks** | 36 baris → 34 daerah (Kamal & Kwanyar agregasi mean), missing=0 | sama |
| **Ladder** | 204 → 74 → 37 (peringkat variansi + StandardScaler) | sama |
| **Grid** | 27 konfigurasi (3 tahap × k=2..10, seed 42) | sama |
| **Pemenang valid** (min_size≥2) | dim **37**, k=2, sil **0.497** (2;32) | dim **204**, k=2, sil **0.529** (32;2) |
| **Cluster kecil** | Labang (Bangkalan) + Nunukan | Jabon, Wonoayu-Sidoarjo |
| **Peta** | `peta_clustering_linear.html` | `peta_clustering_poly.html` |

Catatan jujur (dibahas penuh di tiap notebook): skor mentah dan valid hampir berhimpit
di linear (mentah tertinggi = pemenang itu sendiri, dim 37/k=2/sil 0.497); konfigurasi
dim 204/k=2 (sil 0.484) justru singleton (Wonoayu) sehingga tersaring. `retained_var` ≈ 1.0
di semua tahap karena variansi didominasi segelintir fitur berskala besar.
Revisi 2026-10-03 (lihat `CHANGELOG.md`): baris Jabon yang degenerat (std 16× terlalu kecil)
diekstraksi ulang dengan pipeline acuan 4.2 — sebelumnya pemenang linear adalah
dim 204/k=2/sil 0.477 dengan cluster kecil {Jabon, Wonoayu, Tanah Merah}.
