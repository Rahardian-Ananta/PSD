# 5.4 Dokumentasi KNIME Workflow — Clustering Polutan

Dokumentasi ini menjelaskan alur kerja (*workflow*) implementasi analisis clustering menggunakan **KNIME Analytics Platform** untuk masing-masing polutan (CO, NO₂, SO₂).

---

## 5.4.1 Overview Workflow

![Workflow KNIME Overview](fig_knime_workflow_overview.png)

**Deskripsi Umum:**
Workflow KNIME melakukan analisis clustering pada dataset gabungan kelas (35 mahasiswa × 68 fitur) untuk setiap polutan secara terpisah. Alur kerja mencakup tahap:
1. **Setup / Konfigurasi** — Load data dari PostgreSQL (Aiven Cloud)
2. **Preprocessing** — Normalisasi fitur
3. **Dimensionality Reduction** — PCA (opsional, untuk Skenario 2)
4. **Clustering** — K-Means dengan berbagai nilai K
5. **Evaluasi** — Silhouette Coefficient & Scoring

### Node 5: Normalizer (Z-Score)

![Normalizer Config](fig_knime_normalizer_config.png)

**Fungsi:** Standarisasi fitur menggunakan metode Z-Score agar setiap fitur memiliki mean=0 dan standard deviation=1.

**Konfigurasi:**
- **Method:** Z-Score (Standardization)
- **Apply to:** Semua kolom fitur

**Penjelasan Matematis:**

Z-Score transformasi dilakukan dengan rumus:

$$z = \frac{x - \mu}{\sigma}$$

dimana:
- $x$ = nilai fitur asli
- $\mu$ = mean dari fitur
- $\sigma$ = standard deviation dari fitur

**Mengapa Normalisasi Diperlukan?**
- K-Means menggunakan jarak Euclidean, sehingga sangat sensitif terhadap skala fitur
- PCA juga membutuhkan data yang sudah distandarisasi agar komponen utama tidak bias ke fitur dengan skala besar
- Tanpa normalisasi, fitur dengan satuan besar (misal: `abs_energy`) akan mendominasi perhitungan jarak

---

### Node 6: PCA (Principal Component Analysis)

![PCA Config](fig_knime_pca_config.png)

**Fungsi:** Reduksi dimensi dari 68 fitur menjadi 37 komponen utama (untuk Skenario 2).

**Konfigurasi:**
- **Number of components:** 37
- **Method:** SVD (Singular Value Decomposition)
- **Scaling:** Tidak dilakukan lagi (sudah dinormalisasi di Node 5)

**Penjelasan Matematis:**

PCA bekerja dengan langkah-langkah berikut:

1. **Matriks Covariance:**
$$C = \frac{1}{n-1} X^T X$$

2. **Eigenvalue Decomposition:**
$$C v = \lambda v$$

dimana $v$ adalah eigenvector (komponen utama) dan $\lambda$ adalah eigenvalue (variance yang dijelaskan).

3. **Proyeksi:**
$$X_{PCA} = X \cdot V_k$$

dimana $V_k$ adalah matriks eigenvector terpilih (37 komponen dengan eigenvalue terbesar).

**Output:** Tabel dengan 35 baris × 37 kolom PCA.

---

### Node 7: K-Means Clustering

![K-Means Config](fig_knime_kmeans_config.png)

**Fungsi:** Melakukan clustering menggunakan algoritma K-Means.

**Konfigurasi:**
- **Number of clusters (K):** 2, 3, 4, 5, 6, 7, 8, 9, 10 (dijalankan untuk setiap K)
- **Max iterations:** 300
- **Number of runs:** 10
- **Random seed:** 42 (untuk reproducibility)
- **Distance measure:** Euclidean

**Penjelasan Matematis:**

K-Means bekerja dengan algoritma berikut:

1. **Inisialisasi:** Pilih K titik pusat (centroids) secara acak
2. **Assignment:** Setiap titik data ditugkan ke centroid terdekat berdasarkan jarak Euclidean:
$$d(x_i, c_j) = \sqrt{\sum_{k=1}^{p} (x_{ik} - c_{jk})^2}$$
3. **Update:** Hitung ulang centroid sebagai rata-rata titik-titik dalam cluster:
$$c_j = \frac{1}{|S_j|} \sum_{x_i \in S_j} x_i$$
4. **Iterasi:** Ulangi langkah 2-3 sampai konvergen (centroid tidak berubah signifikan)

**Objective Function (Inertia/WCSS):**
$$J = \sum_{j=1}^{K} \sum_{x_i \in S_j} \|x_i - c_j\|^2$$

Inertia yang lebih rendah menunjukkan cluster yang lebih compact.

---

### Node 8: Scorer (Silhouette Coefficient)

![Scorer Config](fig_knime_scorer_config.png)

**Fungsi:** Mengevaluasi kualitas cluster menggunakan Silhouette Coefficient.

**Konfigurasi:**
- **Column:** Label cluster dari K-Means
- **Distance measure:** Euclidean

**Penjelasan Matematis:**

Silhouette Coefficient untuk setiap titik $i$ dihitung dengan:

$$s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}$$

dimana:
- $a(i)$ = rata-rata jarak titik $i$ ke semua titik lain dalam cluster yang sama (intra-cluster distance)
- $b(i)$ = rata-rata jarak minimum titik $i$ ke semua titik di cluster terdekat yang berbeda (nearest-cluster distance)

**Interpretasi:**
- $s(i) \approx 1$ → Titik berada jauh dari cluster tetangga (cluster yang baik)
- $s(i) \approx 0$ → Titik berada di batas antara dua cluster
- $s(i) \approx -1$ → Titik mungkin berada di cluster yang salah

**Silhouette Score Rata-rata:**
$$\bar{s} = \frac{1}{n} \sum_{i=1}^{n} s(i)$$

Skor rata-rata mendekati 1 menunjukkan clustering yang berkualitas tinggi.

## 5.4.3 Alur Kerja Lengkap (Flow)

```
CSV Reader / DB Reader
        |
        v
  Column Filter (drop metadata)
        |
        v
    Normalizer (Z-Score)
        |
        v
  ┌─────────────────┐
  │  Skenario 1:    │    Skenario 2:
  │  Tanpa PCA      │    PCA (68 → 37)
  └────────┬────────┘         |
           |                  v
           |          PCA (n_components=37)
           |                  |
           v                  v
      K-Means (K=2..10)
           |
           v
    Silhouette Coefficient
           |
           v
    Evaluasi & Perbandingan
```

## 5.4.4 Konfigurasi Parameter Penting

| Parameter | Nilai | Keterangan |
|-----------|-------|------------|
| K (jumlah cluster) | 2 - 10 | Dicari K optimal dengan Elbow & Silhouette |
| Max iterations | 300 | Batas iterasi maksimum K-Means |
| Number of runs | 10 | Jumlah inisialisasi acak |
| Random seed | 42 | Untuk reproducibility |
| PCA components | 37 | Jumlah komponen utama yang dipertahankan |
| Normalization | Z-Score | Standarisasi (mean=0, std=1) |
| Distance measure | Euclidean | Untuk K-Means dan Silhouette |
