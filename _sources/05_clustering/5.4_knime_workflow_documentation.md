# 5.4 Dokumentasi KNIME Workflow — Clustering Polutan

Dokumentasi ini menjelaskan alur kerja (*workflow*) implementasi analisis clustering menggunakan **KNIME Analytics Platform** untuk masing-masing polutan (CO, NO₂, SO₂).

---

## 5.4.1 Overview Workflow

```{figure} ./fig_knime_workflow_overview.png
:width: 70%
:align: center
:alt: Overview Workflow KNIME

Overview Workflow KNIME
```

**Deskripsi Umum:**
Workflow KNIME melakukan analisis clustering pada dataset gabungan kelas (file CSV fitur hasil ekstraksi TSFEL) untuk setiap polutan secara terpisah. Alur kerja mencakup tahap:
1. **Setup / Data Ingestion** — Load data dari file CSV gabungan polutan (CO, NO₂, atau SO₂)
2. **Preprocessing** — Kolom filtering dan normalisasi fitur (Z-Score)
3. **Dimensionality Reduction** — PCA (opsional, untuk Skenario 2 menyusutkan 68 fitur menjadi 37 fitur)
4. **Clustering** — K-Means dengan berbagai variasi nilai K
5. **Evaluasi** — Silhouette Coefficient & Scoring

### Node 3: Normalizer (Z-Score)

**Fungsi:** Standarisasi fitur menggunakan metode Z-Score agar setiap fitur memiliki rata-rata ($\mu = 0$) dan deviasi standar ($\sigma = 1$).

```{figure} ./fig_knime_normalizer_config.png
:width: 80%
:align: center
:alt: Normalizer config

Normalizer (Z-Score) — konfigurasi
```

**Konfigurasi:**
- **Method:** Z-Score (Standardization)
- **Apply to:** Semua kolom fitur numerik terpilih

**Penjelasan Matematis:**

Z-Score transformasi dilakukan dengan rumus:

$$z = \frac{x - \mu}{\sigma}$$

dimana:
- $x$ = nilai fitur asli
- $\mu$ = mean dari fitur
- $\sigma$ = standard deviation dari fitur

**Mengapa Normalisasi Diperlukan?**
- K-Means menggunakan perhitungan jarak Euclidean, sehingga sangat sensitif terhadap perbedaan skala antar fitur.
- PCA membutuhkan data yang sudah distandarisasi agar komponen utamanya tidak bias terhadap fitur dengan rentang nilai yang sangat besar.

---

### Node 4: PCA (Principal Component Analysis) — *Skenario 2*

**Fungsi:** Reduksi dimensi dari 68 fitur menjadi 37 komponen utama esensial untuk Skenario 2.

```{figure} ./fig_knime_pca_config.png
:width: 70%
:align: center
:alt: PCA config

PCA — konfigurasi
```

**Konfigurasi:**
- **Number of components:** 37
- **Method:** SVD (Singular Value Decomposition)
- **Scaling:** Tidak dicentang ulang (karena data sudah dinormalisasi pada node sebelumnya).

**Penjelasan Matematis:**

PCA bekerja melalui tahapan berikut:
1. **Matriks Covariance:** $C = \frac{1}{n-1} X^T X$
2. **Eigenvalue Decomposition:** $C v = \lambda v$ (mencari eigenvector $v$ dan eigenvalue $\lambda$).
3. **Proyeksi:** Mereduksi dimensi dengan mengambil 37 komponen utama ber-eigenvalue terbesar ($X_{PCA} = X \cdot V_k$).

**Output:** Tabel baru dengan dimensi tereduksi menjadi 37 kolom komponen utama.

### Node 5: K-Means Clustering

**Fungsi:** Mengelompokkan data ke dalam $K$ klaster menggunakan algoritma K-Means.

```{figure} ./fig_knime_kmeans_config_1.png
:width: 70%
:align: center
:alt: K-Means config 1

K-Means — konfigurasi 1
```

```{figure} ./fig_knime_kmeans_config_2.png
:width: 70%
:align: center
:alt: K-Means config 2

K-Means — konfigurasi 2
```

**Konfigurasi:**
- **Number of clusters (K):** Dijalankan secara iteratif (misal: $K = 2$ sampai $10$) untuk mencari titik optimal.
- **Max iterations:** 300
- **Number of runs:** 10
- **Random seed:** 42 (untuk memastikan hasil dapat direproduksi / *reproducibility*)
- **Distance measure:** Euclidean Distance

**Penjelasan Matematis:**
Algoritma meminimalkan *Objective Function* (Inertia / Within-Cluster Sum of Squares):
$$J = \sum_{j=1}^{K} \sum_{x_i \in S_j} \Vert{}x_i - c_j\Vert{}^2$$
dimana $c_j$ adalah titik pusat (*centroid*) dari klaster $S_j$.

---

### Node 6: Scorer (Silhouette Coefficient)

**Fungsi:** Mengevaluasi seberapa baik pemisahan antar klaster terbentuk menggunakan *Silhouette Coefficient*.

```{figure} ./fig_knime_scorer_config.png
:width: 80%
:align: center
:alt: Scorer config

Scorer (Silhouette Coefficient) — konfigurasi
```

**Konfigurasi:**
- **Category column:** Label klaster hasil output K-Means
- **Measure:** Euclidean

**Penjelasan Matematis:**
Silhouette Score untuk setiap titik $i$ dihitung berdasarkan perbandingan jarak intra-klaster $a(i)$ dan jarak inter-klaster terdekat $b(i)$:
$$s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}}$$
Nilai rata-rata $\bar{s}$ mendekati 1 mengindikasikan struktur klaster yang sangat baik dan terdefinisi dengan jelas.

## 5.4.4 Konfigurasi Parameter Penting

| Parameter | Nilai | Keterangan |
|-----------|-------|------------|
| Sumber Data | File CSV (`co.csv`, `no2.csv`, `so2.csv`) | Data gabungan kelas per polutan |
| K (jumlah cluster) | 2 - 10 | Variasi pengujian mencari K terbaik |
| Max iterations | 300 | Batas iterasi maksimum algoritma K-Means |
| Random seed | 42 | Menjaga konsistensi hasil acak |
| PCA components | 37 | Target reduksi dimensi (Skenario 2) |
| Normalisasi | Z-Score | Menyamakan skala varians fitur |
