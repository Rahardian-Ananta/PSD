# 2.1 Data Collection — Apa dan Dari Mana Datanya

Tahap *Data Collection* (CRISP-DM) menjawab pertanyaan paling dasar sebelum analisis apa pun:
**data apa yang dikumpulkan, dari satelit/instrumen apa, untuk wilayah mana, pada periode kapan,
dan dalam bentuk apa data itu disimpan.** Proyek ini memakai **dua sumber citra satelit** yang
berbeda peran, keduanya diunduh lewat openEO (*Copernicus Data Space Ecosystem*):

| Aspek | Sentinel-5P (TROPOMI) | Sentinel-2A (MSI) |
| :--- | :--- | :--- |
| **Peran** | Deret waktu polutan udara (bahan clustering Bab 5) | Citra multispektral (bahan klasifikasi sawah Bab 6) |
| **Wilayah** | Kecamatan Jabon, Sidoarjo (`jabon.geojson`) | Kecamatan Jabon, Sidoarjo (`jabon.geojson`) |
| **Periode** | 31 Agu 2025 – 31 Agu 2026 (366 hari, harian) | Komposit median 5–26 Agu 2026 |
| **Produk** | L2 kolom densitas gas, dirata-rata harian + spasial | L2A *surface reflectance* per piksel |
| **Luaran** | CSV per polutan + gabungan + *rolling-30* + ZIP | `s2_jabon.tif` + `s2_jabon_metadata.json` |
| **Detail** | Sub-bab 2.1a | Sub-bab 2.1b |

Kedua sub-bab berikut adalah notebook interaktif yang mendemonstrasikan proses pengunduhannya
langkah demi langkah (koneksi openEO → definisi *cube* → *batch job* → unduh → verifikasi).
Alur hilirnya: deret 5P dipakai di 2.2 (deskripsi dataset) sampai Bab 5 (clustering 204 fitur),
sedangkan citra 2A dipakai di Bab 6 (100 poligon sawah/non-sawah → RandomForest → peta prediksi).
