# 2.4 Identifikasi Missing Value

Dokumen ini menyajikan hasil identifikasi nilai kosong (*missing value*) pada dataset kualitas udara **Kecamatan Jabon, Kabupaten Sidoarjo** periode **31 Agustus 2025 s.d. 31 Agustus 2026**.

---

## 2. Penyebab Missing Value

Missing value pada data Sentinel-5P Kecamatan Jabon disebabkan oleh faktor berikut:

### A. Tutupan Awan (*Cloud Cover*)
Sensor TROPOMI pada Sentinel-5P tidak dapat mengukur konsentrasi polutan dengan akurat ketika terdapat tutupan awan tebal. Selama musim hujan di Jawa Timur (Oktober–April), frekuensi tutupan awan tinggi menyebabkan banyak observasi harian yang tidak valid.

### B. Geometri Orbit Satelit
Sentinel-5P beroperasi pada orbit polar dengan periode revisit ±1 hari. Pada beberapa hari, wilayah Kecamatan Jabon mungkin tidak tercakup oleh lintasan orbit pada kondisi pengamatan yang optimal.

### C. Keterbatasan Sensor CH4
Metana (CH₄) memiliki *missing rate* sangat tinggi (77.32%) karena algoritma retrieval CH₄ memerlukan kondisi atmosfer yang sangat bersih (awan sangat sedikit atau tidak ada sama sekali) untuk menghasilkan data yang valid.

## 4. Penanganan

Seluruh missing value akan ditangani pada **BAB 3 Preprocessing** menggunakan:
1. **Deteksi Outlier (IQR)** terlebih dahulu — nilai pencilan dikonversi ke `NaN`
2. **Interpolasi Linear Berbasis Waktu** — `df.set_index('date').interpolate(method='time').ffill().bfill()`

Setelah preprocessing, seluruh 366 titik waktu pada setiap polutan akan terisi penuh (0 NaN).
