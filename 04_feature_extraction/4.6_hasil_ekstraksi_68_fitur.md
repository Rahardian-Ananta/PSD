## 2. Ingestion Hasil Ekstraksi ke Cloud Database PostgreSQL Aiven

Setelah berkas `NO2_Jabon_TSFEL.csv` berhasil dihasilkan dari proses ekstraksi, data dimasukkan ke dalam basis data bersama PostgreSQL Aiven kelas.

> [!IMPORTANT]
> **Ketentuan Integrasi Database:**
> 1. **Kolom Identitas Tambahan**: Wajib menambahkan kolom **`nama`** (`Rahardian Ananta`) dan **`daerah`** (`Kecamatan Jabon`) pada baris fitur sebelum diunggah.
> 2. **Batas Koneksi (*Connection Limit*)**: Server memiliki batas maksimal **20 koneksi bersamaan**. Setelah data berhasil di-insert, koneksi harus segera ditutup (*engine dispose / logout*) agar mahasiswa lain dapat mengakses database.

### Script Python Ingestion ke Aiven:

```python
import pandas as pd
from sqlalchemy import create_engine

# 1. Baca berkas hasil ekstraksi 68 fitur TSFEL
features_df = pd.read_csv('NO2_Jabon_TSFEL.csv')

# 2. Tambahkan kolom identitas wajib
features_df.insert(0, 'nama', 'Rahardian Ananta')
features_df.insert(1, 'daerah', 'Kecamatan Jabon')

print("Bentuk tabel sebelum upload:", features_df.shape)
print("Kolom identitas:", features_df[['nama', 'daerah']].to_dict(orient='records'))

# 3. Kredensial Koneksi PostgreSQL Aiven (Sesuai panduan pertemuan 3)
DB_USER = "avnadmin"
DB_PASS = "<PASSWORD_AIVEN_ANDA>"
DB_HOST = "habiba-psd-integrasi-psd.l.aivencloud.com"
DB_PORT = "19662"
DB_NAME = "defaultdb"

DB_URI = f"postgresql://{DB_USER}:{DB_PASS}@{DB_HOST}:{DB_PORT}/{DB_NAME}?sslmode=require"

# 4. Unggah data ke tabel target
engine = create_engine(DB_URI)
try:
    with engine.connect() as conn:
        # Masukkan ke tabel fitur bersama
        features_df.to_sql('ekstraksi_fitur_no2', con=conn, if_exists='append', index=False)
        print("✅ Data fitur NO2 Kecamatan Jabon berhasil diunggah ke Aiven PostgreSQL!")
finally:
    # Selalu tutup engine untuk membebaskan kuota connection limit (max 20)
    engine.dispose()
    print("🔒 Koneksi database berhasil ditutup (Log out aman).")
```
