- K-Means Clustering menggunakan 68 fitur asli
- Pencarian Optimal K menggunakan Elbow Method & Silhouette Score

Skenario 2 (PCA Dimensionality Reduction):
- Reduksi dimensi dari 68 fitur menjadi 35 fitur menggunakan PCA
- K-Means Clustering pada 35 fitur PCA
- Pencarian Optimal K menggunakan Elbow Method & Silhouette Score

------------------------------------------------------------------------
1.3 Error Handling (NaN)
------------------------------------------------------------------------
ERROR SEBELUMNYA:
- ValueError: Input X contains NaN
- PCA does not accept missing values encoded as NaN natively

SOLUSI:
- Menambahkan SimpleImputer dari sklearn.impute
- Strategi imputasi: median (robust terhadap outlier)
- Imputasi dilakukan SEBELUM standarisasi dan PCA

7. ERROR YANG DIPERBAIKI
========================================================================

ERROR: ValueError: Input X contains NaN
- Lokasi: 5.1_reduksi_dimensi_pca.ipynb, Cell In[4], line 7
- Penyebab: Dataset mengandung nilai NaN/missing values
- PCA tidak menerima missing values secara native

SOLUSI:
- Import SimpleImputer dari sklearn.impute
- Tambahkan imputasi median sebelum StandardScaler
- Kode yang ditambahkan:
  
  from sklearn.impute import SimpleImputer
  
  # Handle NaN values with median imputation
  nan_count = np.isnan(X).sum()
  if nan_count > 0:
      print(f'{p}: Ditemukan {nan_count} nilai NaN, melakukan imputasi median...')
      imputer = SimpleImputer(strategy='median')
      X = imputer.fit_transform(X)

Catatan: Strategi median dipilih karena robust terhadap outlier yang 
mungkin ada dalam data fitur TSFEL.
